    Regression testing

    End-to-end tests of cardano-node and cardano-cli on a local Cardano testnet. They run every night against the latest node from the master branch, in several setups, and on demand for each node release.

    Upgrade testing

    One run in three steps. Step 1 starts a cluster on the released node and runs the tests. Step 2 upgrades all nodes but one pool, so old and new versions run side by side, and runs the tests again. Step 3 completes the upgrade, with a hard fork when one is due, and runs them a third time.

        About these numbers

        Regression
        The system-level test suite against a local Cardano testnet, run nightly and for node releases.
        Upgrade
        One run in three steps across a node upgrade. It counts as one run; its tests are the sum of the three steps.
        Tests executed
        Every test that ran, in every run and step. Skipped tests are not counted.
        CLI invocations
        How many times the tests ran a cardano-cli command, and how many transactions they submitted.

        CI runs come from GitHub Actions. Local runs are uploaded by developers from their own machines. The page checks for new data every 60 seconds.
